{%- comment -%} Google Analytics 4. The old `analytics.js` / `ga('create', 'UA-...')` snippet that used to live here targeted Universal Analytics, which Google shut down in July 2023 -- it kept loading on every page but recorded nothing. Set `google_analytics:` in _config.yml to a GA4 measurement ID ("G-XXXXXXXXXX") to enable tracking. A leftover "UA-" ID is ignored rather than silently loading a script that does nothing. {%- endcomment -%} {%- assign ga_id = site.google_analytics | strip -%} {%- if ga_id contains "G-" -%} {%- endif -%}
